# 🤖 AI Code Reviewer

An AI-powered code review tool that analyzes your code and provides
instant feedback using Google Gemini API.

## 🛠️ Tech Stack
- **Frontend:** React, Monaco Editor, React Markdown
- **Backend:** Node.js, Express
- **AI:** Google Gemini 2.5 Flash

## 🚀 Features
- Real-time code editing with Monaco Editor
- AI-powered code review
- Markdown formatted feedback
- Syntax highlighting
- Resizable panels

## ⚙️ Installation

### Frontend
cd Frontend
npm install
npm run dev

### Backend
cd Backend
npm install
node server.js

## 🔑 Environment Variables
GOOGLE_API_KEY=  _api_key_here
